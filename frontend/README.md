# Angular Frontend MVP

## Setup

1. `cd frontend`
2. `npm install --legacy peer deps`
3. `npm start`

## Funktionalität

- Drei-spaltiges Layout
- Linke Spalte: oben Platzhalter für Zusammenfassung, unten Chat-Verlauf / Sessions
- Mittlere Spalte: Übersichtsbereich und Chatbot-Interface
- Rechte Spalte: Platzhalter für zukünftige Diagramme

Das ist ein MVP mit lokalem Chatverlauf und CSV-Dateiupload-Placeholder.
